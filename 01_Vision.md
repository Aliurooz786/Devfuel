# DevFuel Vision Document

## Project Name

DevFuel

## Version

Phase 0 - Truth Collection System

---

## Problem Statement

The user wants to improve health, lifestyle, productivity, and self-awareness.

Currently there is no consistent system to capture daily life events.

Important events are forgotten, patterns are invisible, and decisions are made using assumptions instead of personal data.

---

## Goal

Create a frictionless life logging platform where a user can write events in natural language.

Examples:

- 1 cigarette pee li
- 2 samose kha liye
- Weight 93.4 hai
- Aaj mood bahut kharab hai
- 30 min walk kari

The system should understand the event and store it automatically.

---

## Success Criteria

A user can log daily events within 5 seconds.

A user can maintain logging for 14 consecutive days.

A user can view all logged events in chronological order.

---

## Non Goals

This version is NOT intended to:

- provide health advice
- predict weight loss
- recommend diets
- calculate calories
- act as an AI coach

The only goal of Phase 0 is data collection.
