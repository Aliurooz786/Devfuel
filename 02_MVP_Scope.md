# DevFuel Phase 0 Scope

## In Scope

### Natural Language Logging

User enters:

- 1 cigarette pee li
- 1 aam kha liya
- mood kharab hai

### Event Parsing

AI identifies:

- Smoking
- Food
- Weight
- Exercise
- Mood
- Sleep
- Alcohol
- Notes

### Database Storage

Store:

- timestamp
- original text
- category
- structured output

### Timeline View

Display all events sorted by time.

### Search

User can search previous logs.

---

## Out Of Scope

The following features are not part of MVP:

- calorie counting
- macro calculation
- AI coach
- weight prediction
- nutrition advice
- recommendation engine
- vector search
- RAG
- multi-agent architecture
- notifications
- reminders
- wearable integrations

If a feature is not listed inside "In Scope", it is considered out of scope.
