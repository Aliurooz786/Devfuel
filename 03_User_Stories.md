# User Stories

## Story 1

As a user

I want to write

"1 cigarette pee li"

So that smoking activity gets logged automatically.

---

## Story 2

As a user

I want to write

"2 samose kha liye"

So that food history gets stored.

---

## Story 3

As a user

I want to write

"Weight 93.5"

So that body weight can be tracked.

---

## Story 4

As a user

I want to write

"Mood bahut kharab hai"

So that emotional events can be logged.

---

## Story 5

As a user

I want to view today's timeline

So that I can review my day.

---

## Story 6

As a user

I want to search previous logs

So that I can find historical events.
